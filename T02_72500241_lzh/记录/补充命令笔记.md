# Linux 命令行基础速查表

## 1. 查看位置与切换目录

| 命令 | 用途 | 示例 |
|---|---|---|
| `pwd` | 显示当前所在目录 | `pwd` |
| `ls` | 列出当前目录的文件和文件夹 | `ls` |
| `ls -lh` | 列出文件，并以易读格式显示大小 | `ls -lh` |
| `ls -a` | 显示隐藏文件 | `ls -a` |
| `cd` | 切换目录 | `cd Documents` |
| `cd ..` | 返回上一级目录 | `cd ..` |
| `cd ~` | 返回当前用户的主目录 | `cd ~` |
| `cd -` | 返回上一次所在的目录 | `cd -` |

## 2. 创建、复制、移动与删除

| 命令 | 用途 | 示例 |
|---|---|---|
| `mkdir` | 创建文件夹 | `mkdir project` |
| `mkdir -p` | 一次创建多层目录 | `mkdir -p a/b/c` |
| `cp` | 复制文件 | `cp a.txt b/` |
| `cp -r` | 复制文件夹及其内容 | `cp -r dir1 dir2` |
| `mv` | 移动文件或文件夹，也可用于改名 | `mv old.py new.py` |
| `rm` | 删除文件 | `rm a.txt` |
| `rm -r` | 删除文件夹及其内容 | `rm -r old_dir/` |

**删除提醒：** `rm` 删除的内容通常不能像回收站文件一样轻易恢复。`rm -rf` 会强制递归删除，使用前一定要确认路径和文件名。

## 3. 查看与搜索内容

| 命令 | 用途 | 示例 |
|---|---|---|
| `cat` | 显示较短文件的全部内容 | `cat a.txt` |
| `less` | 分页查看较长文件 | `less log.txt` |
| `grep` | 在文件内容中搜索关键词 | `grep -n "error" log.txt` |
| `find` | 按名称查找文件 | `find . -name "*.py"` |

说明：

- `grep -n` 会同时显示匹配内容所在的行号。
- `find .` 表示从当前目录开始查找。
- `"*.py"` 加引号可以避免星号先被命令行展开。

## 4. 权限与安装软件

| 命令 | 用途 | 示例 |
|---|---|---|
| `sudo` | 临时以管理员权限执行命令 | `sudo apt update` |
| `chmod` | 修改文件权限 | `chmod +x run.sh` |

`chmod +x run.sh` 通常用于给脚本添加可执行权限。`apt` 是 Ubuntu、Debian 等系统常用的软件包管理工具；其他 Linux 发行版的安装命令可能不同。

## 5. 查看磁盘、测试网络与压缩文件

| 命令 | 用途 | 示例 |
|---|---|---|
| `df` | 查看磁盘空间 | `df -h` |
| `ping` | 测试网络连接 | `ping -c 4 baidu.com` |
| `tar` | 解压 `.tar.gz` 压缩包 | `tar -xzf a.tar.gz` |
| `tar` | 将文件夹打包为 `.tar.gz` | `tar -czf archive.tar.gz folder/` |

`-h` 表示用易读的单位显示；`ping -c 4` 表示发送 4 次网络测试请求。`tar -xzf` 适用于 gzip 压缩的 tar 文件，例如 `.tar.gz`。

## 一个常见的操作顺序

```bash
pwd                  # 确认当前目录
ls                   # 查看目录内容
mkdir -p project     # 创建项目目录
cd project           # 进入项目目录
```
