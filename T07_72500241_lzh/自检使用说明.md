## 1. 四色图片自检（不需要摄像头）

```powershell
python .\T07_72500241_lzh\代码\check_t07.py
```

调用你的 hw_track_live.detect_color，分别检测课程原版 素材/patterns.png 的四种颜色。输出质心、与已知真值的误差、检测 FPS 和 PASS/FAIL。

真值来自课程 gen_images.py 的 patterns()：红圆 (480,270)，蓝方块 (1470,270)，绿三角 (480,643.33)，黄圆 (1440,800)。误差要求不超过 15 像素，每种颜色的检测 FPS 至少为 15。计时不包括读图片、画图和显示，不等同于摄像头的实际 FPS。

## 2. 用电脑摄像头做基础统计

将红色圆形目标放到镜头前，再运行：

```powershell
python .\T07_72500241_lzh\代码\check_t07.py --source 0 --show
```

程序先测四色图片，再用 T06 的 detect_red_circle 连续处理最多 60 帧，打印帧数、命中数、命中率和实际处理 FPS。基础要求：至少 30 帧、命中率至少 70%、FPS 至少 10。显示窗口中按 q 可提前结束，但不足 30 帧会判失败。

## 3. 用视频或手机网络流做基础统计

```powershell
python .\T07_72500241_lzh\代码\check_t07.py --source "C:\实际位置\红圆视频.mp4" --show
python .\T07_72500241_lzh\代码\check_t07.py --source "http://手机实际IP:4747/video" --show
```

替换示例路径/IP 为实际值。视频不足 30 帧或打不开时不会伪造通过；不会重复循环短视频来凑帧数。命中是“检测函数返回非 None”，与教案统计定义一致，不代表逐帧人工审核后的正确识别率。

## 保存与提交

输出保存在 T07_72500241_lzh/自检结果/：

- T07_check_日期时间.txt：真实终端统计内容。
- T07_check_日期时间.json：对应的数值记录。
- T07_patterns_check.png：四色静态自检标记图。
- T07_basic_last_frame.png：运行基础视频统计后保存的最后一帧标记图。

日志有时间戳；PNG 是最近一次成功生成的标记图。截图时保留执行命令与本次实际输出。运行失败时不能用旧 PNG 证明本次通过。

静态自检图不是实时追踪截图。T07 提交还要保留 hw_track_live.py 的真实追踪截图或约 5 秒录屏，展示当前颜色、FPS、质心坐标和按键切换。基础视频统计没有运行时，日志会明确写“未运行”。

本自检脚本不修改你的检测函数，不自动证明断流重连或资源释放的全部运行行为，也不自动提交或推送 GitHub。
